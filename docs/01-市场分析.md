# 01 市场分析 — Android 深度定制超级 AI 助手

> 阶段：市场分析 / 原型选型 | 日期：2026-08-18

## 1. 市场现状：手机 AI Agent 竞争格局

### 1.1 产业玩家全景

| 阵营 | 代表 | 形态 | 操控深度 | 系统权限 |
|------|------|------|---------|---------|
| 手机厂商系统级 | 华为小艺+MateAI、荣耀 YOYO、小米超级小爱、OPPO/vivo、三星 Gauss（Bixby 换代） | 系统内置助手，多模态+主动 | 系统 API 级（厂商特权） | 最高（系统内置） |
| 云大厂 Agent | 智谱 AutoGLM（GLM-PC/手机）、阿里通义、字节豆包 | 云端 Agent + 手机端容器 | App 级 UI 自动化（部分免 root） | 中（无障碍/录屏） |
| 海外生态 | Google Gemini Live、Apple Siri+LLM（2026 深度集成）、OpenAI 高级语音模式 | 系统助手+语音优先 | 系统级（Apple）/ 受限（Android） | 中高 |
| 开源/研究 | Mobile-Agent（蚂蚁）、AppAgent、Clawd、OpenClaw、Hermes、Kestrel、MiraAgent | UI Agent / 个人助理框架 | 无障碍/ADB/节点 | 低-中 |
| 终端黑客生态 | Termux + Hermes/OpenClaw 自托管 | 消息网关 + Agent 内核 | 几乎为零（无 UI 操控） | 低（沙盒内） |

### 1.2 关键趋势（2025–2026）

1. **从"问答聊天"到"主动 Agent"**：行业共识从被动聊天机器人转向"理解用户 + 主动行动"的系统级助理。华为 MateAI、小米超级小爱均宣称"主动式、场景化"。
2. **语音优先（Voice-first）**：Gemini Live、ChatGPT 语音模式、Clowder Voice Companion 均验证"hands-free 语音对话"是下一交互入口；**音色/语气/语调（人设化语音）成为差异化卖点**（Clowder 每猫独立声线、荣耀/小米音色商店）。
3. **端侧模型崛起**：sherpa-onnx（ASR/TTS/VAD/声纹全家桶）、Qwen 小模型、NPU 加速，使"无网可用的本地语音栈"成为可能；无 GMS 国产机（华为/荣耀）是端侧方案的刚需场景（Kestrel 已实证）。
4. **UI Agent 商业化前夜**：AutoGLM、Clawd 证明"一句话操控 App"可行；痛点仍是稳定性（UI 改版崩）、速度（每次走模型）、信任（支付红线）。
5. **AOSP 深度定制回归**：厂商定制 ROM（HUANGLONG mp730 等）与系统级 Agent 结合，是"机器人大脑级"助手的最深形态（MiraAgent 方向）。

### 1.3 市场规模与用户画像

| 用户群 | 需求 | 支付意愿 | 竞争强度 |
|--------|------|---------|---------|
| 重度手机用户（自动化/效率） | 一句话点外卖、订票、比价、多 App 联动 | 中 | 高（AutoGLM 等） |
| 无 GMS 国产机用户（华为/荣耀） | 本地语音栈、无谷歌依赖 | 中高 | 低（厂商助手弱） |
| 老人/无障碍用户 | 语音操控、免学习、大字体朗读 | 高 | 低（刚需未被满足） |
| 开发者/极客 | Termux 自托管、可编程 Agent、MCP | 中 | 低 |
| 儿童教育/陪伴 | 人设语音、角色陪伴 | 中高 | 中（豆包等） |
| IoT/车机/平板/电视 | 跨设备控制、D-pad 遥控（Kestrel v2.0 TV） | 中 | 低 |

**结论**：红海在"聊天助手"，蓝海在"**可自主行动的语音人设助手 + 本地优先隐私**"交叉点。

## 3. 市场机会与差异化定位

### 3.1 机会点（Gap 分析）

1. **"本地语音全家桶 + 人设声线"无人做**：竞品要么云 TTS（依赖网络/延迟/隐私），要么无 TTS。端侧 sherpa-onnx（ASR/TTS/声纹/VAD 一套 C++ 栈）+ Clowder 式"参考音频克隆"音色模型 = 唯一"离线可用、每角色独立声线"方案。
2. **"Pi 级 Agent 内核 + Termux 可编程"无人做**：Hermes 证明 Termux 可跑完整 Agent，但**只做消息网关不做手机操控**；本项目补上"大脑（Termux/Pi）+ 躯体（Java/C++ 硬件与操控桥）"的拼图。
3. **"AOSP 深度定制 Agent"处于早期**：MiraAgent 是需求文档阶段，无成品；厂商助手不开放。先以普通 App 形态（免 root）交付、再向 ROM 层演进是务实路径。
4. **无 GMS 机型刚需**：华为/荣耀无 GMS、厂商助手语音能力弱（Kestrel 实证 EMUI 环境），端侧语音栈 + a11y 操控可直接填补。
5. **技能自学习差异化**：Kestrel "越用越快"（技能缓存）对用户是可感知的；竞品每次走云模型。

### 3.2 定位语

> **"随身超级 AI 助理：把 Pi 级智能大脑装进 Termux，把手机变成它的躯体——能听（ASR+声纹）、能说（人设 TTS）、能看（屏幕识别）、能动手（按键/触屏/手势）、能感知（传感器/振动），越用越懂你。"**

### 3.3 差异化支柱（4 条）

| 支柱 | 来源 | 不可替代性 |
|------|------|-----------|
| P1 本地语音全家桶+人设声线 | clowder-ai × sherpa-onnx | 隐私/离线/音色三合一，竞品均为云 |
| P2 Pi 级可编程大脑（Termux） | pi agent-core × Termux | Agent 内核即社区生态（Steering/工具/事件流），非自研玩具 |
| P3 深度操控+技能自学习 | Kestrel 双路径 × Action DSL | 真机实战验证过的确定性原语，非理论 |
| P4 系统级权威+渐进信任 | MiraAgent 五平面/不变量 | 长期演进至 ROM 层的架构地基 |

## 4. 风险与市场障碍

| 风险 | 说明 | 缓解 |
|------|------|------|
| 厂商后台限制 | EMUI iAware 杀无障碍服务/后台 | Kestrel A11yRebinder 模式（已实证） |
| 权限收紧 | 新 Android 版本收紧无障碍/录屏 | 分层授权 + HITL 兜底 + TV 语义点击替代路线 |
| 平台政策 | 自动操控类 App 上架风险 | 侧载/厂商渠道为主，透明合规文案 |
| 技术门槛 | Termux+JNI+多模块集成复杂度 | 脚手架化（本项目即脚手架） |
| 成本 | 云端模型调用费 | 技能缓存 + 端侧模型优先 |

---

## 5. 结论

- 市场处于"UI Agent 商业化前夜 + 语音人设兴起 + 端侧模型成熟"三浪交汇期；
- **机会窗口**：本地语音全家桶 + 可编程 Agent 内核 + 深度操控 + 技能自学习四合一无人占据；
- **切入策略**：先普通 App（免 root、免刷机）覆盖无 GMS 国产机与极客人群，验证后向 AOSP 深度定制（MiraAgent 方向）演进。
