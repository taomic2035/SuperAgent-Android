**公共部分（强协作）**：契约三处（contract.json / Protocol.kt / types.ts）、docs/05/06/07/12 基线——任何一方修改前必须在 handoff 写通报（改什么/为什么），改后跑契约镜像测试；单点精准编辑；不互相覆盖（pull --rebase 再改）。

### 1.6 git 协作规约（双方提交均适用）

1. 提交前 `git pull --rebase`；禁止 force push（修自己刚推的署名类瑕疵除外）
2. 每个提交必带署名尾行（`Co-Authored-By: <本方标识>`），消息说清为什么
3. 禁删除文件（移 d:	mp trash）；不提交密钥/二进制/模型（.gitignore 一票否决域）
4. 跨域改动（动到对方主责区域）在提交信息注明「跨域：<原因>」
