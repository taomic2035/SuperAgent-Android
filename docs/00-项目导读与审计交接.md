## 1. 一句话项目

**SuperAgent-Android**：Android 手机上的系统级 AI 助手——Termux 里跑 brain（TypeScript + pi-agent-core + GLM-4.6v），Android 原生 body（Kotlin，无障碍服务 + sherpa-onnx 语音）执行感知/操控/HITL，HTTP RPC 通信。产品承诺：**"语音→规划→操控→证据→固化→回放"真机闭环**，安全铁律（支付红线/敏感会话/隐私脱敏）优先于一切功能。

## 4. 架构铁律（AD-01~09 见 docs/09，违反即架构回退）

1. **brain/body 分权**：brain 只做规划（pi 内核 + 守卫），感知/操控/语音/技能/HITL/词表权威全在 body；COMMIT_BOUNDARY 硬拦在 body 双闸（selectOption 词表 + **tap 落点校验**——2026-08-19 真机实证坐标绕行后堵死）。
2. **pi 只用核心 Loop**（Agent + pi-ai），AgentHarness/Session 等周边不用（AD-05 论证）。
3. 复用成熟方案（Kestrel/agentos-android）但不为复用而复用（AD-06/06-B 有逐项采纳/不采纳结论）。
4. M3 本地模型**无工具仅闲聊**（弱模型+控制权=安全反模式）。
5. **契约纪律**：跨端类型唯一真源 `body/common/src/main/resources/contract.json`，改任一侧先改契约，双侧镜像测试拦截漂移（CT-05）。

- **红线（用户明确）**：git commit/push 仅编排 agent（GLM-5.3）可做；**禁止删除文件与批量刷改**（要删移 `d:\tmp\super-agent-trash-<日期>\`，修改只做单点精准编辑）；执行 agent 不改 brain/body 源码；不碰真实支付。
- 资源策略：异步执行类任务优先 handoff 给 deepseek（低成本），编排侧子 agent 只做高耦合/实时（设备调试、喂主线的源码挖掘）。

## 9. 给审计者（GPT 5.6）的建议切入点

1. **安全面**（最高价值）：tap 落点校验的绕过面（多节点重叠/坐标边缘）、敏感会话 action 放行的时效滥用、契约镜像未覆盖的 RPC 参数面。
2. **正确性**：回放签名闸的假阴性（稳定签名抹除过于激进？）、止损豁免通道的滥用面（speech.say 豁免是否合理）、模型降级链的脑裂（切换后 vision/relevance 仍绑主模型）。
3. **资源**：BodyServer 幂等缓存无 TTL、blob 目录滚动策略在 capture 失败路径的泄漏、EventBus 512 条的语义。
4. 一切结论以**真机证据**为准（docs/handoff/ 是证据账本），纸面推断需标注"未验证"。
