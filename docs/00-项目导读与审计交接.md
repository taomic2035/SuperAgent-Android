## 1. 一句话项目

## 4. 架构铁律（AD-01~09 见 docs/09，违反即架构回退）

1. **brain/body 分权**：brain 只做规划（pi 内核 + 守卫），感知/操控/语音/技能/HITL/词表权威全在 body；COMMIT_BOUNDARY 硬拦在 body 双闸（selectOption 词表 + **tap 落点校验**——2026-08-19 真机实证坐标绕行后堵死）。
2. **pi 只用核心 Loop**（Agent + pi-ai），AgentHarness/Session 等周边不用（AD-05 论证）。
3. 复用成熟方案（Kestrel/agentos-android）但不为复用而复用（AD-06/06-B 有逐项采纳/不采纳结论）。
4. M3 本地模型**无工具仅闲聊**（弱模型+控制权=安全反模式）。
5. **契约纪律**：跨端类型唯一真源 `body/common/src/main/resources/contract.json`，改任一侧先改契约，双侧镜像测试拦截漂移（CT-05）。
