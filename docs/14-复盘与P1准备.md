## 2. 复盘：做错了什么（教训）

| 教训 | 根因 | 改进 |
|---|---|---|
| **TTS 修了 5 轮才通** | 每次修症状不修根因：noCompress 只配 onnx → espeak 守卫 → copyAssetsDir → 回调签名 → 全量 noCompress。真正的根因是 sherpa 需要**全部**资产 STORED | **首次修复前读完上游源码+文档**，不要假设"只改这一处就够了" |
| **UX-01 重写引入回归** | 改了 Kotlin（statusContainer: LinearLayout）但没同步 XML（仍是 TextView）→ ClassCastException 启动即崩 | **跨层变更（XML+Kotlin / TS+JSON）必须一次提交内同步**——CI 应加布局编译检查 |
| **UX 验证 agent 四次失败** | 网络断连×2 + 限额×1 + 超时×1——基础设施问题非代码问题 | **关键验证降级为手动**（DeepSeek 在场时直接指令它做，不依赖 agent） |
| **前期"总是停"** | 派活后写长汇报→结束回合→等通知——用户看来是停了 | **完成→立刻下一件→不汇报**（用户 8-19 明确反馈后修正） |
| **文档滞后** | 代码改完→提交→忘记同步 docs/06 FR 状态 | **每次提交 self-check：改了代码是否需要同步 05/06/07/08** |
